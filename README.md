# Rīgas rudens rogainings 2026 — TOP 10 maršrutu salīdzinājums

Neoficiāls interaktīvs 4 h distances TOP 10 komandu KP secības, atzīmēšanās laika un aptuvenas kustības salīdzināšanas skatītājs.

## Kā publicēt GitHub Pages

1. Izveido publisku repozitoriju GitHub, piemēram, `rogaining-viewer`.
2. Augšupielādē **visus trīs failus** (`index.html`, `.nojekyll`, `README.md`) repozitorija saknē. Vienkāršāk augšupielādēt `index.html` un `README.md` (fails `.nojekyll` ir papildinošs).
3. Repozitorijā atver **Settings → Pages**.
4. Pie **Build and deployment** izvēlies **Source: Deploy from a branch**, **Branch: main**, **Folder: /(root)** un **Save**.
5. GitHub Pages publicēs vietni adresē `https://TAVS-LIETOTAJS.github.io/rogaining-viewer/` (pielāgo lietotājvārdu un repozitorija nosaukumu).

## Kas jau ir iekļauts

- 2026. gada Rīgas rudens rogaininga 4 h distances TOP 10 komandu oficiālo KP secība un pulksteņa laiki
- ar roku precizētas kontrolpunktu koordinātas un starta/finiša punkts
- interaktīva karte un laika slīdnis; KP salīdzinājums; punktu grafiks
- sacensību kartes attēls ir iegults `index.html`, tādēļ papildu attēla fails nav vajadzīgs

## Svarīgi pirms publiskas pieejamības ieslēgšanas

Sacensību kartes attēls ir no **rogainings.lv**. Pirms karti iegulto HTML padarīt publisku, noskaidro organizatoru vai kartes tiesību turētāja atļauju attēla pārpublicēšanai.
